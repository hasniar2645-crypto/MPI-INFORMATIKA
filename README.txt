MPI STRUKTUR DATA — PETUNJUK PENGGUNAAN

Isi paket:
- index.html : halaman utama MPI
- style.css  : desain responsif
- app.js     : navigasi, simulasi, kuis, asesmen, dan refleksi

CARA MENJALANKAN
1. Ekstrak file ZIP ke folder di komputer.
2. Buka folder MPI_Struktur_Data.
3. Klik dua kali index.html atau buka dengan Chrome/Edge/Firefox.
4. Tidak perlu instalasi server; aktivitas utama berjalan offline.
5. Untuk mengunggah secara online, unggah index.html, style.css, dan app.js ke layanan hosting statis (misalnya GitHub Pages atau Netlify). Pastikan struktur folder tetap sama.

CATATAN PEMBELAJARAN
- Materi adalah pengantar struktur data dengan bahasa sederhana.
- Kuis dan asesmen dinilai otomatis di browser.
- Refleksi hanya ditampilkan pada sesi berjalan dan tidak dikirim ke server.
- Silakan edit isi HTML untuk menyesuaikan kelas, identitas guru, atau kurikulum.
